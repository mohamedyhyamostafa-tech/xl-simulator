💡 فكرة المشروع



ZAEEM DB ULTRA هو نظام إدارة قواعد بيانات ويب خفيف الوزن، متطور، ومستقل بذاته (Standalone)، مبني بـ PHP (باستخدام نمط البرمجة كائنية التوجه OOP) ويعتمد بالكامل على محرك SQLite المدمج.


الفكرة الأساسية وراء المشروع هي تقديم "لوحة تحكم قواعد بيانات" سريعة للغاية، آمنة، وتعمل بالكامل بتقنية AJAX (بدون أي إعادة تحميل للصفحة)، بحيث تدمج قوة وسرعة قواعد البيانات مع واجهة مستخدم سلسة وفورية تشبه تطبيقات سطح المكتب، ودون الحاجة لتثبيت سيرفرات قواعد بيانات خارجية معقدة.


🚀 المميزات الرئيسية
هندسة صفحة واحدة (Single Page Application): واجهة تفاعلية فورية مدعومة بالكامل بـ AJAX دون إعادة تحميل.



محرك SQLite مدمج: يعتمد على قواعد بيانات SQLite سريعة وخفيفة مع دعم الفهارس الحقيقية (Real Indexes).

تقسيم الصفحات الحقيقي (SQL Pagination): مصمم خصيصاً للتعامل مع كميات ضخمة من البيانات بكفاءة وبدون استهلاك موارد السيرفر.

نظام حماية تشفير متطور: حماية Vault مدعومة بـ libsodium وتأمين كامل لحساب المشرفين.



أدوات إدارة متكاملة:

إنشاء وحذف قواعد البيانات والجداول بضغطة زر.

إضافة وتعديل وحذف الصفوف والأعمدة بسهولة.

أدوات متقدمة للفرز (Sort)، التصدير والاستيراد (Export/Import)، توليد البيانات الوهمية (Generate Data)، والبحث عن التكرارات (Find Duplicates).

نظام تخصيص ألوان الصفوف (Row Colors) والتبديل بين الثيمات (Theme Toggle).

💡 Project Overview


ZAEEM DB ULTRA is an advanced, lightweight, and standalone web-based database management system built with Object-Oriented PHP (OOP) and powered by embedded SQLite.


The core concept of the project is to provide an ultra-fast, secure, and fully interactive database administration dashboard driven entirely by AJAX (No Page Reloads). It bridges the gap between high-performance data operations and a sleek, desktop-like user interface, all without requiring heavy external database servers.


🚀 Key Features
Single-Page Architecture (SPA): Seamless and instant user experience powered entirely by asynchronous AJAX requests.


Embedded SQLite Engine: Utilizes lightweight, high-performance SQLite databases with real SQL-level indexing.


Robust SQL Pagination: Architected specifically to handle massive datasets smoothly with zero performance lag.


Encrypted Vault Security: Secured using libsodium cryptographic library and hardened administrator access control.


Comprehensive Toolset:


Dynamic database and table creation/management.


Advanced row/column manipulation and data editing.


Built-in utilities for sorting, exporting, importing, bulk data generation, and duplicate detection.


Customizable row color-coding and dynamic theme switching.

Frontend: Modern JavaScript (AJAX / Fetch API), CSS3, Responsive UI Design
